# Tawi Outdoor | September campaign data

Sample data covering eight campaigns across Google Ads, Meta Ads and TikTok Ads. The files are available through Windsor File.

Spending covers September 1-23, 2026. All amounts are in USD, and dates use Nairobi time.

- **campaign-daily.csv** contains 184 daily spending records, including days with no spend.
- **campaign-budgets.csv** contains the eight September budgets, campaign start and end dates, current status and planning notes. The budgets total $39,000.

Account and campaign IDs link the two files. Each row also has a source reference. JSON copies contain the same records as the CSVs.
