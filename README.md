# Tawi Outdoor | Windsor B8-33

Before-state materials for the budget-pacing benchmark. Surface: Web. Comparison: ChatGPT Work / Claude Cowork. The scored run is read-only.

Source data: [CSV files and definitions](data). Two Windsor File datasets are used: tawi_b8_33_daily and tawi_b8_33_budgets. These contain 184 daily spend rows and eight approved campaign budgets covering three fictional ad accounts. The account is zz215@expert.micro1.ai.

Review on September 24, 2026 using complete September 1-23 data in Africa/Nairobi. The scenario includes different flight dates and current statuses, so a straight 30-day extrapolation for every campaign is insufficient.

All records are synthetic. No native paid-ad accounts are connected. This tests Windsor retrieval and budget-pacing analysis, not native ad-account authentication. Do not describe the simulated account IDs as live advertising accounts.

Run build-fixture.cjs to reproduce the source and expected calculations. Keep sources unchanged for both runs. Screenshots are saved separately in Downloads/B8-33_Windsor_Before/Screenshots, not in the public data folder. The evidence folder holds setup verification and expected calculations, not scored model outputs.
